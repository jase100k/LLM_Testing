# LLM_Testing

A collection of experiments, prototypes, and benchmarks testing local and frontier Large Language Models (LLMs) on code generation, web games, and application design.

## Projects

- **[asteroid-bonsai](asteroid-bonsai/)**: Asteroids arcade game prototype generated during testing with **Ternary Bonsai 2 28B MTP**.
- **[asteroid-qwen-unleashed-Q3K](asteroid-qwen-unleashed-Q3K/)**: Asteroids arcade prototype generated with **Qwen 3.8 27B Unleashed (Q3_K_XL)**.
- **[asteroid-qwen-unleashed-Q3K-v2](asteroid-qwen-unleashed-Q3K-v2/)**: Full-featured, self-contained Asteroids arcade game generated autonomously in 18 minutes by **Qwen 3.8 27B Unleashed (Q3_K_XL)** with 3-layer parallax starfield, procedural asteroids, Web Audio API sound synthesis, CRT scanlines, and glassmorphic HUD.
